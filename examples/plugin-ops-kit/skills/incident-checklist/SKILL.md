# 故障响应清单

1. **确认现象**：错误率、延迟、可用性指标；确认影响范围（租户/地域/功能）。
2. **定级**：P0（核心不可用）/ P1（部分降级）/ P2（轻微）；同步给值班负责人。
3. **止血优先**：回滚最近变更、关闭开关、扩容、限流，先恢复再定位。
4. **记录时间线**：每个动作记录时间、执行人、结果，为复盘保留证据。
5. **根因分析**：从变更、依赖、容量、数据四个方向排查；避免在止血阶段做大规模重构。
6. **复盘**：24 小时内产出复盘文档，包含时间线、根因、影响、改进项与负责人。
